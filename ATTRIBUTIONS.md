# Atribuições e dependências visuais

O código final usa a identidade e os componentes locais da Pixel Code Studio. Padrões de interação foram estudados em recursos externos e reimplementados para o projeto.

| Recurso | Aplicação no código | Licença |
|---|---|---|
| [Motion](https://github.com/motiondivision/motion) | Transições de rota, reveal, FAQ, menu, showcase e feedback de hover | MIT |
| [21st.dev](https://21st.dev/community/components) | Estrutura de project showcase, accordion e CTA adaptada nos componentes locais | conforme o componente; apenas padrões MIT selecionados |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Pesquisa, design system persistido, contraste, hierarquia e responsividade | MIT |
| [Phosphor Icons](https://github.com/phosphor-icons/react) | Iconografia funcional e social do site | MIT |
| [LDRS](https://github.com/GriffinJohnston/ldrs) | Indicador Ring no carregamento assíncrono de páginas | MIT |

O relatório detalhado de acesso, uso e descarte está em `docs/portfolio-resource-map.md`.
