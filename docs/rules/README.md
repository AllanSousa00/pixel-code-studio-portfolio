# Regras do projeto

Esta pasta guarda a constituição operacional da Pixel Code Studio para que o contexto sobreviva entre agentes e sessões. [`AGENTS.md`](../../AGENTS.md) é a entrada obrigatória.

| Arquivo | Abrangência |
|---|---|
| `global-rules.md` | Preflight, postflight, autoridade, dados, arquitetura e princípios permanentes |
| `design-rules.md` | Identidade Pixel, tokens, dials de Taste, anti-slop e motion |
| `frontend-rules.md` | React/Vite, rotas, assets, componentes, SEO e UX |
| `backend-rules.md` | Fronteira com backend, pagamentos, banco e serviços compartilhados |
| `discord-rules.md` | Limites do bot/dashboard e preservação de Components V2 |
| `security-rules.md` | Headers, CSP, dados, autenticação e privacidade |
| `testing-rules.md` | Lint, typecheck, testes, Playwright, QA visual e performance |
| `compliance-matrix.md` | Regras verificáveis, severidade, evidência e automação |
| `external-tools.md` | Repositórios estudados, commits fixados, licenças e decisões de uso |

O relatório da auditoria completa atual é [`docs/rules/full-compliance-audit.md`](full-compliance-audit.md). O relatório de entrega do portfólio fica em [`docs/portfolio-final-audit.md`](../portfolio-final-audit.md).
