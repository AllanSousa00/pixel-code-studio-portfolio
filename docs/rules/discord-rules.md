# Regras de Discord

O bot e a dashboard ficam fora do escopo deste portfólio público. Suas áreas preservadas são loja, pedidos, propostas, pagamentos, projetos, manutenção, tickets, denúncias, avaliações, moderação, segurança e auditoria.

Quando esse sistema for alterado, bot e dashboard devem continuar consumindo os mesmos serviços de domínio. A interface Discord deve usar Components V2 (Container, Section, Text Display, Thumbnail, Media Gallery, Separator, Action Row, Button e Select conforme suportado) e não voltar a embeds legados quando Components V2 atender ao caso. Não invente CSS/comportamento que o Discord não oferece.

Assets do Discord usam semantic keys; IDs não ficam espalhados no código. O portfólio não contém comandos, login administrativo, painéis ou dados de membros e não deve reintroduzir as features removidas Perfil/Personalizar Perfil, Atividades e Jogos e grupos/LFG.
