# Home — regras específicas

- Ordem: hero → faixa contínua → projetos destacados → serviços → cases → criador → tecnologias → processo → avaliações → FAQ → CTA.
- O hero identifica Pixel, serviços e autoria em até dois blocos de texto.
- A captura real do Vértice ENEM é a imagem principal acima da dobra; não recebe lazy loading.
- O showcase alterna quatro projetos a cada 6,2 segundos e oferece abas e pausa.
- A área de Allan é ampla, violeta e usa placeholder neutro até a foto real ser fornecida.
- Avaliações sem autorização mostram estado vazio e apontam para as entregas públicas.
- O CTA principal é “Falar sobre um projeto” ou “Solicitar um orçamento”.
